# Laocoön · Зонд окон

[中文](../README.md) · [English](README.en.md) · **Русский** · [Français](README.fr.md) · [Español](README.es.md) · [العربية](README.ar.md) · [Deutsch](README.de.md) · [Português](README.pt.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [हिन्दी](README.hi.md) · [Italiano](README.it.md)

> Под Троей все хотели втащить этого деревянного коня в город. Не поверил только Лаокоон.
> Он вонзил копьё ему в брюхо — и услышал внутри лязг оружия.
>
> Этот инструмент делает то же самое: **ткни в окно и услышь, что в нём спрятано.**

Вы видите незнакомое окно — возможно, что-то нехорошее. Нажмите `F2`, наведите перекрестие, щёлкните. Программа выложит всё, что можно вытащить об этом окне и о процессе за ним.

- Один файл `Laocoon.exe`, около **202 КБ**
- Никаких сторонних зависимостей — только .NET Framework 4.x, который уже есть в Windows (Win10 / Win11, ставить ничего не надо)
- Без сети, без выгрузки данных, без записей в реестр, без файлов настроек, без фонового агента (распаковал, запустил — на диске ничего не остаётся)
- Двенадцать языков внутри: **中文 / English / Русский / Français / Español / العربية / Deutsch / Português / 日本語 / 한국어 / हिन्दी / Italiano**

> Имя файла — ASCII `Laocoon.exe`, а в заголовке окна остаётся `Laocoön` с диерезисом.
> Так пути, командные строки, вложения в письмах и CI никогда не спотыкаются о не-ASCII символы.

## Как пользоваться

1. Двойной щелчок по `Laocoon.exe` (для самых полных данных — **правый клик → «Запуск от имени администратора»**)
2. Нажмите `F2` — курсор станет перекрестием
3. Наведите на нужное окно: его обведёт синяя рамка, а рядом появится небольшой чёрный HUD с классом, заголовком, PID и родительским окном в реальном времени
4. **Левый клик** — захват и сбор; **правый клик** или **Esc** — отмена
5. Полный отчёт появляется сразу: окно, процесс, файл, подпись, скрытые окна и дочерние элементы — всё в одном месте

Сбор одноразовый: ничего не обновляется по таймеру, ничего не висит в фоне. Закрыли окно — ничего не осталось, кроме файла, который вы сами сохранили кнопкой «Сохранить отчёт».

Почему именно эти двенадцать: за основу взяты языки пяти постоянных членов Совета Безопасности ООН, плюс **арабский** (единственный рабочий язык ООН, который в этом списке пропущен), **немецкий / португальский / японский / корейский** (крупные экономики и софтверные экосистемы), **хинди** (самый большой рынок одного языка по населению) и **итальянский** (европейская культура). Турецкого, индонезийского, вьетнамского и польского нет — точка расширения оставлена: добавить язык = добавить одну таблицу в `Lang.cs`.

При первом запуске язык выбирается в таком порядке:

```
--lang=xx в командной строке  >  язык системы  >  английский
```

То есть на китайской системе стартует китайский, на русской / французской / испанской / арабской / немецкой / португальской / японской / корейской / хинди / итальянской — свой, остальные получают английский (региональные варианты вроде `pt-BR`, `zh-Hant`, `ar-EG` тоже распознаются). Переключение действует только до конца текущего запуска — настройки никуда не сохраняются; чтобы зафиксировать язык, запускайте `Laocoon.exe --lang=ru` (или создайте ярлык с этим аргументом).

Переводится не только интерфейс, но и **текст отчёта** — метки, заголовки разделов и эвристические подсказки («исполняемый файл лежит во временной папке», «у процесса есть ещё N скрытых окон верхнего уровня») создаются на текущем языке.

### Как сделан арабский (справа налево)

Арабский — это не «заменить таблицу строк». На тестах вылезли три ловушки:

1. **Зеркальный интерфейс**: вся форма переворачивается через `RightToLeftLayout`, панель идёт справа налево, главная кнопка оказывается у правого края.
2. **Отчёт не зеркалится**: внутри пути, хеши, имена классов окон. Зеркалирование переворачивает начало и конец каждой строки, поэтому поле отчёта всегда слева направо. Только **страница приветствия** (обычный текст) в арабском выравнивается вправо.
3. **Двоеточие уезжает влево от метки**: BiDi в GDI считает двоеточие в конструкции «арабская метка + `:` + латинское значение» частью правого RTL-фрагмента и рисует `0 :المقبضx0001048E`. Лечится нулевой ширины LRM (U+200E) с обеих сторон двоеточия — она принудительно задаёт направление; та же изоляция применяется к аргументам форматирования (даты, PID, имена классов), иначе дата превращается в `04:28:37 08-11-2026`. Эксперимент со всеми вариантами остался в диагностике `--biditest`, так что при переписывании можно просто прогнать его снова.

У **деванагари** (хинди) тоже нет фиксированной ширины знака, как и у арабского, поэтому «добить пробелами до выравнивания» только портит картину. В этих двух языках отчёт переключается на формат `метка: значение` — лучше без выравнивания, чем с фальшивым.
Арабский, хинди, японский и корейский используют системные шрифты Windows (Segoe UI / Nirmala UI / Yu Gothic UI / Malgun Gothic); если шрифта нет, происходит автоматический откат — без квадратов и без исключений.

## Что собирается

| Категория | Содержимое |
|---|---|
| Окно | Дескриптор, класс, заголовок, биты стиля (разобранные в имена `WS_*` / `WS_EX_*`), прямоугольник, клиентская область, видимость / свёрнутость, **поверх всех**, **окно-инструмент**, **скрытое DWM**, окно-владелец |
| Элемент под курсором | Вплоть до дочернего контрола: класс, ID контрола, текст, путь от корневого окна до него |
| Процесс | PID / TID, полный путь, **командная строка**, родитель (имя + PID), архитектура (x86 / x64 / WOW64), **повышенные права**, сеанс, время запуска |
| Файл | Размер, даты создания / изменения, **MD5 / SHA1 / SHA256**, компания, продукт, описание, версия файла, копирайт |
| Цифровая подпись | Наличие встроенной подписи, подписант, издатель, срок действия, результат проверки цепочки |
| Модули | Полные пути всех DLL, загруженных процессом |
| Окна процесса | **Все** окна верхнего уровня этого процесса, включая скрытые (помечены `[скрыто]`) — фоновому окну вредоносной программы здесь не спрятаться |
| Дерево контролов | Всё дерево дочерних элементов целевого окна: отступы, размеры, ID, текст |
| Подозрительные признаки | Эвристика: лежит в Temp / «Загрузках» / AppData, без подписи, без названия компании, поверх всех, число скрытых окон, файл создан за последние 7 дней и т. п. (**только подсказки, не приговор**) |

Весь отчёт — простой текст: колонки выровнены, разделы разделены; можно выделить и скопировать всё, либо нажать «Сохранить отчёт» и записать `.txt` в UTF-8. Чтобы проверить файл дальше, скопируйте `sha256` туда, куда доверяете: инструмент собирает данные только локально, никуда не подключается и ничего не отправляет.

## Известные ограничения

- **Цифровая подпись**: проверяется только встроенная в PE. Файлы самой Windows (например, `notepad.exe`) подписаны через каталог, поэтому здесь будет «встроенная подпись не найдена» — это нормально.
- Без прав администратора у процессов с повышенными правами или защищённых не читаются путь / модули / командная строка (будет «недостаточно прав»), остальные поля в порядке.
- `WM_GETTEXT` для текста контролов ждёт не больше 60 мс на неотвечающих окнах (`SMTO_ABORTIFHUNG`), чтобы интерфейс не зависал; из-за этого у единичных зависших окон текст не читается.
- Дерево контролов — максимум 240 элементов, список модулей — 400; дальше ставится пометка об усечении.
- Хеширование ограничено 512 МБ, больше — пропускается (чтобы не ждать минутами).
- Язык интерфейса идёт за системой; вне этих двенадцати — английский. Переводы написаны руками, а термины Windows (`WS_*` / `WS_EX_*`, `DWM Cloaked`) намеренно оставлены по-английски, чтобы каждый переводчик не придумывал свой словарь.
- Арабский интерфейс зеркальный, но **отчёт всегда слева направо** — внутри технические данные, при зеркалировании их не прочитать. Это сделано намеренно, а не недоделанный перевод.

## Сборка своими руками

Нужен .NET SDK (8 или новее). Двойной щелчок по `build.bat`, либо:

```bat
dotnet build src\Laocoon.csproj -c Release
```

Результат — `src\bin\Release\net48\Laocoon.exe`.

> В `build.bat` переменная `TEMP` намеренно указывает на локальную папку `.tmp`: на некоторых машинах системный временный каталог недоступен для записи, и сборка падает сразу.

## Исходники

- `src/Laocoon.cs` — сама программа, около 2225 строк, только Win32 P/Invoke, ни одного пакета NuGet
- `src/Lang.cs` — ядро языков (перечисление, определение, подбор шрифта, ширина, выбор строки, откат) и все двенадцать таблиц в одном файле, около 2250 строк
- `src/Laocoon.ico` — сам пиксельный значок (8 размеров, 16–256); создаётся из сетки 16×16 скриптом `tools/make_icon.py`

В каждой таблице 124 ключей, все компилируются в exe. Ни `.resources`, ни satellite assembly — поэтому на любой машине с Win10/11 всё работает сразу, без «нет языкового пакета, откат на английский».

Основные точки входа:
- `Probe.HitTest` — сам обходит окна верхнего уровня в z-порядке для попадания (не `WindowFromPoint`, чтобы не попасть в собственный оверлей)
- `Probe.DeepestAt` — спускается через `ChildWindowFromPointEx` до самого внутреннего контрола
- `Probe.Collect` — собирает окно / процесс / файл / подпись / модули / соседние окна / дерево контролов
- `FrameForm` / `HudForm` — прозрачная синяя рамка и следящий HUD при прицеливании (оба `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`, мышь не перехватывают)
- `L.T` / `L.F` — выбор строки и форматирование с подстановками; отсутствующий ключ откатывается на английский, а не в пустоту

## Диагностические ключи (для работы с кодом)

```
Laocoon.exe --selftest out.txt     собрать консольное окно, напечатать отчёт и записать его в файл
Laocoon.exe --aimtest              самопроверка попадания и оверлея прицела
Laocoon.exe --i18ncheck            проверить 12 языков: полнота ключей, ширина колонок, шрифты, направление
Laocoon.exe --langswitch           пройти по всем языкам и сверить текст интерфейса и отчёт
Laocoon.exe --focustest f.log [shot.png]  переключить все 12 языков и проверить, что фокус в списке сохраняется
Laocoon.exe --biditest out.png     сравнение 8 вариантов вёрстки bidi (арабский + латиница)
Laocoon.exe --lang=ru              запуск на заданном языке (в ini не пишется)
Laocoon.exe --uishot out.png --lang=ar            отрисовать интерфейс в PNG
Laocoon.exe --uishot out.png --lang=ar --welcome  только страница приветствия
Laocoon.exe --uishot out.png --lang=ar --screen   снимать экран (DrawToBitmap рисует ложное выделение в RTL-полях)
```

Вместе с `--lang=` снимок позволяет за один проход отрисовать все двенадцать интерфейсов и проверить их глазами.
